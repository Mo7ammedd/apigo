# Security policy

Security fixes target the current `0.1.x` release line.

Report security concerns privately to the repository owner, [@Mo7ammedd](https://github.com/Mo7ammedd). If you have access to this private repository, use a private issue with a minimal reproduction. Do not publish exploit details or paste credentials, encryption keys, customer specifications, or production responses.

Include the apigo version, Node.js version, operating system, affected command, and a reproduction using disposable local data.

The [README security model](README.md#security-model) describes local encryption, key ownership, redaction, reference resolution, redirect handling, and limitations. apigo does not send telemetry or execute scripts embedded in OpenAPI/Postman documents.
