# Changelog

## 0.1.0 — MVP

- ESM CLI for Node.js 22+, packaged with an executable npm binary.
- Direct HTTP requests, headers, queries, bodies, timeouts, scoped TLS settings, and machine output.
- OpenAPI 3.0/3.1 and Swagger 2.0 import from JSON, YAML, URLs, and local files.
- Operation discovery, schema inspection, reference bundling, request generation, validation, and interactive required fields.
- Encrypted SQLite persistence with migrations, environments, authentication, saved overrides, and redacted history.
- Collection browsing, preflight, and sequential execution.
- OpenAPI refresh and diffs with potentially breaking change detection.
- Postman v2 import/export and measured verbose diagnostics.
- Vitest coverage, package installation smoke tests, cross-platform CI, and development documentation.

Deferred: TUI, advanced OAuth2 flows, multipart/file uploads, binary responses, and JSON Schema dynamic references.
